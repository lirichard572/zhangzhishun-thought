# 张至顺（米晶子）认知蒸馏Skill

## 简介

本项目基于张至顺道长（号米晶子，全真龙门派第二十一代传人）的三部著作，蒸馏其认知框架，生成可运行的 Codex Skill。

## 素材来源

| 书籍 | 内容主题 |
|------|----------|
| 《炁体源流》上下册 | 丹道修炼、心性本体、玄关火候 |
| 《金刚长寿功》 | 外刚内柔功法、性命双修 |
| 《济世良方》 | 医道济世、辨证施治 |

## 使用方法

在 Codex 对话中输入：
- 「用米晶子的方式分析……」
- 「潮汐蒸馏张至顺」
- 「帮我蒸馏米晶子的认知」
